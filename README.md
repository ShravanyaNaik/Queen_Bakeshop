Queen Bakeshop – Online Bakery Management System

Overview

Queen Bakeshop is a web-based bakery application designed to provide an organised platform for presenting bakery products and managing customer interactions.

Technologies:
PHP
MySQL 
HTML
CSS
JavaScript

Key Features:

Product browsing and management
Customer registration and authentication
Product search and filtering
Shopping cart functionality
Order management
Responsive user interface
Retain only the features implemented in your application.

Installation:

Clone the repository.
Install XAMPP or another compatible PHP/MySQL environment.
Place the project in the server's web directory.
Create the database using the supplied SQL file.
Configure database credentials locally.
Start Apache and MySQL.
Open the application in your browser.

Security:

Never commit database credentials.
Use password hashing.
Validate user inputs.
Use prepared SQL statements.

Future Enhancements:
